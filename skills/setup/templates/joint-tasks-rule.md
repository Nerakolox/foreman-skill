# 联调任务单

适用：两个以上的仓都要动的活。开单、续写、勾清单、归档之前读这份。

## 规矩

- 开工前先翻 `joint-tasks/`，有相关的就续写，没有再新建。
- 一个任务一份文件，文件名是 `YYYY-MM-DD-短名.md`，短名用英文小写加连字符。
- 新开一张单，同时在 `plan/tasks.md` 加一行，仓写「多仓」，说明里写任务单文件名。台账怎么改见 `.agents/rules/plan.md`。
- 「契约变更」里的每一条，必须先在 `spec/` 落地、打上勾，各仓才能开始勾自己的清单。
- 每个仓只勾自己那一栏，不碰别人的。
- 状态只有三个：`planning` → `in_progress` → `done`。
- 全部做完，对着「联调验证」逐项验收，状态改成 `done`，然后立刻把文件移进 `_archive/joint-tasks/`，同时把台账那一行改成 `已完成`。
- 引用契约只写章节号，不复制原文。

## 模板

```markdown
# <短名>

- 状态：planning
- 台账：plan/tasks.md 第 <序号> 行
- 开单：YYYY-MM-DD
- 涉及：<子仓>、<子仓>

## 背景

<要解决什么问题，一两句>

## 契约变更

- [ ] <改了什么>，见 §<N.M>

## <子仓> 清单

- [ ] <这个仓要做的事>

## <子仓> 清单

- [ ] <这个仓要做的事>

## 联调验证

- [ ] <端到端要验证的场景>

## 记录

<过程中的决定、遇到的问题，按日期追加>
```
